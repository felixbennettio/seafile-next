# 客户端剩余迁移清单

更新日期：2026-10-12。按用户指定，固定以下客户端顺序；每项只补齐尚未完成的部分。已交付的功能移出待办，不因其他功能变更重新迁移。功能完成需要入口接通、相关回归通过及安装包交付；真实设备验收另行记录，不混入源码迁移待办。

## 1. Android

当前没有确认的源码迁移缺口。原 Java/JNI 入口、备份、传输、编辑器、媒体、系统文档提供程序、外部分享和设置均参与现有构建。已发布刷新、收藏、旧 SSO 异常处理及固定签名修复。后续出现具体运行问题时单独处理，不重复重写已保留的功能。
