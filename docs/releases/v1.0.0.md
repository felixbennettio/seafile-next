Seafile Next 将 Android、iOS、macOS、Windows、Linux 和 Docker 服务端整合为一个项目，让不同设备共享一致的账号、资料库和文件体验。

- 支持部署在域名下的自定义路径，修复登录、文件访问、分享和服务端跳转中写死根路径的问题。
- iOS 和 macOS 采用 Apple 原生界面，并在支持的系统上使用 Liquid Glass；支持多账户、资料库浏览、目录操作、上传下载和文件预览。
- 支持密码、双重验证和服务器配置的 OIDC / SAML 单点登录；Apple 客户端支持现代服务器的默认浏览器授权，并提供旧服务器的兼容登录入口。
- 修复 Mac 密码与 SSO 登录的设备信息兼容问题，登录失败时显示具体的账号、验证码或参数错误；网络中断后不再重复提交已使用的两步验证码。
- 支持文件与文件夹收藏。打开预览与取消收藏分开，取消收藏需要确认，刷新失败时保留已有列表。
- iPhone 新增原生文本和 Markdown 编辑，保存后回传；中断或冲突时保留本地草稿，可恢复、导出或另存副本。
- iPhone 增加前台照片备份，支持视频、Live Photo 配对资源、相册选择、Wi-Fi 限制及可选 HEIC/HEIF 转 JPEG；重复扫描不重复上传，格式切换保留已有备份。
- iPhone 增加相邻图片切换、缩放和照片信息，以及原生视频控件、原文件分享和保存到照片。
- iPhone 和 iPad 可直接播放动画 GIF，从收藏打开动画照片也能播放，切换到后台后返回继续查看。
- iPhone 恢复系统分享菜单入口，可保存文件、照片、视频、文字和网页链接，选择账号、资料库及目录，并由应用锁保护。中断后在传输页保留本地副本，可核对服务器内容、继续上传或导出，已确认的文件不会重复发送。
- iPhone 照片备份授权后和从系统设置返回时及时更新权限状态。
- Apple 客户端新增独立传输列表，显示上传下载进度，支持取消、重试、保存本地副本和恢复队列记录；切换目录后传输仍继续，离开页面后不会突然打开预览。
- iPhone 已启动的传输和照片备份可在系统允许的短暂后台时段继续；系统收回后台时间时保留记录和本地文件。
- Apple 客户端支持按名称、大小、类型和修改时间排序目录。
- 改善网络中断和临时 TLS 握手失败后的恢复，登录和目录加载失败时显示错误与重试入口。
- 提供 iOS「文件」App 与 macOS Finder 文件集成；macOS 保留桌面同步、开机启动设置和非沙盒直装版本。
- 改善 Android 刷新与异常处理，修复 macOS 开机启动状态设置；保留 Windows 和 Linux 桌面同步体验。
- Mac 登录输入框恢复正常编辑，并提供清晰边界和左对齐输入；补齐 Dock 图标隐藏、代理、语言、账号设置，以及同步错误和大量删除确认；升级时保留已保存的设置。
- Mac 设置按基本、高级、语言、网络、账号和关于分项显示，修复独立设置窗口顶部分类重叠；电脑名称位于基本设置最上方，保存按钮固定在右下角，成功保存后自动关闭设置窗口。
- 减少 Mac 直装版网络请求和后台检查触发的重复钥匙串确认；取消授权后停止自动重复请求，重新登录与保存设置后正确更新凭据。
- Apple 客户端增加 Wiki 目录与页面入口，支持创建、重命名、删除、发布和取消发布，并保留旧版、共享和群组 Wiki。
- Apple 客户端增加文档评论与回复，支持修改、处理和删除；网络中断时保留尚未确认的输入，避免重复提交。
- Mac 支持资料库创建、批量复制移动、共享权限、服务器搜索和活动；使用默认应用编辑文件后回传，并保留尚未上传的编辑。
- Mac 非沙盒版支持 Finder 同步状态徽标与右键操作，并提供带完整性校验的更新安装。Windows 补充文件资源管理器集成，Linux 补充本地文件链接关联。
- 修复 Windows 和 Linux 的单点登录设置保存，服务器登录能力变化后可正确更新账号状态。
- Android 收藏刷新失败时保留离线缓存，连续刷新或切换账号后不会被较早结果覆盖；账号及网络诊断不再记录登录凭据、验证码和带签名的下载地址。
- 修复 Android 收藏预览遇到缺失文件标识时的异常，并在无法确认缓存内容时重新获取文件。
- Android 旧服务器单点登录遇到损坏或已注销的授权信息时安全提示，不再因此闪退；相关诊断不记录账号、授权地址或证书详情。
- Windows 和 Linux 登录正确提供默认设备名称并兼容服务器的设备信息限制；Linux 补齐浏览器本地文件链接入口。
- 服务端统一使用 `ghcr.io/felixbennettio/seafile-next-server`，支持根路径和子路径部署，并修复网页 SSO 登录返回地址丢失参数的问题。

- iPhone 支持批量复制、移动、删除和下载，按账号保存最近使用的目标目录；部分失败后保留已完成项目。
- iPhone 支持创建、删除和退出资料库，管理用户与群组共享权限，并设置分享密码和到期时间。
- iPhone 增加服务器搜索、活动与变更详情，以及 Face ID、Touch ID 或设备密码应用锁。

Android 提供固定调试签名 APK；Windows 提供未签名便携 ZIP；Linux 提供 amd64 DEB；macOS 提供 Apple Silicon 非沙盒直装 ZIP（尚未公证）。iOS 和 macOS 同时通过现有内部 TestFlight 测试组提供安装。

原生 Apple 客户端仍处于测试阶段。iOS 的自动后台照片备份、合并 Motion Photo、文档协作编辑、Files 自定义操作、本地加解密及完整语言覆盖等原客户端功能尚未全部迁移，详见各平台功能审查。

新版 Android 使用固定签名。首次从之前的调试 APK 切换时，需要先保留尚未上传的本地文件再重新安装；以后版本可使用同一签名覆盖升级。
